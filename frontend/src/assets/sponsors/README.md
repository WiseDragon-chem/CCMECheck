# 赞助商图片

首页与「我的」页最下方那个循环展示框，用的就是这个目录里的图。

**增删赞助商不需要改任何代码**：往这里丢一张图，它就出现在展示框里；删掉，它就不见了。
（开发服务器下立刻生效；线上是构建期资源，构建产物带内容哈希，所以要重新构建部署。）

## 命名

```
01-化学与分子工程学院.png
02-某某科技.png
```

- **前面的序号定播放顺序**，按文件名排序，所以请用 `01`、`02` 这样的两位数前缀。
- **去掉序号后的部分会被读屏软件读出来**（它就是图片的 `alt`），所以请写成能让
  人听懂的名字，别用 `banner1`、`logo` 这种。留空或只有序号时，会退回一句
  「赞助商图片」。

## 图片建议

- 格式：PNG / JPG / WebP。
- 宽度 ≥ 1000px，单张 ≤ 300KB。
- **图片铺满可用宽度，最多 500px；高度按图片自己的比例 —— 图多大，框就多高。** 所以：
  - **横长条（4:1 上下）最合适**：高度等于「宽度 ÷ 比例」，横条只占一条，
    方图能占掉大半屏，竖图会更夸张；
  - **同一批图请用同一个比例。** 多家赞助商时框的高度取**最高的那一张**，
    比它矮的图在下面留白（图不会被裁掉、也不会被拉扁）—— 比例不齐时这段
    留白一眼能看出来；
  - 图片本来的比例不会被改，白底的图直接放就好，不会显出一块白方块；
  - **页面会因此滚动。** 这是产品定的口径：赞助图尽量大，宁可页面出现滚动条。
    以前这里靠把图压到 88–160px 来保住参赛者端「一屏放得下」，那个做法已经作废；
  - **宽度上限 500px**：手机显示 380px 宽，桌面收到 500px 并在内容列里居中。
    给更宽的图也不会显示得更大，所以 1000px（500 的 2 倍，管住高清屏）就够了，
    再宽只是白占体积。反过来给不足 500px 的图会被放大、发虚。

## 注意

**这个目录里的图片不入库。** `frontend/.gitignore` 挡着它们（只放行本文件），
图由组织者自己保管 —— 所以：

- 换了图，**要在有图的那台机器上重新构建并部署**，否则线上不会变；
- 反过来，**没有图的机器构建出来的产物里一个赞助位都没有**（页面正常，
  只是这一块整个不渲染）。CI 或换台机器发布时要留意这一点。

这里的图是**公开资源**，会随前端一起发给所有人，别放内部资料。

打卡证明那类私有图片走的是另一套（服务端私有存储 + 短期签名地址），
与本目录无关。
